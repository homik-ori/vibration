# Changelog

Все заметные изменения приложения `vibration`.

## [1.0.0] — 2026-11-26

### Добавлено

- **Музыка**: импорт локальных файлов (`.mp3`, `.wav`, `.m4a`, `.flac`, `.aiff`) через `fileImporter`
  с копированием в приватную папку приложения.
- **Плеер**: обложка с пульсирующим в такт басам градиентом, таймлайн с текущим/общим временем,
  play/pause, перемотка ±15 с, список библиотеки.
- **Движок вибрации**: real FFT на `Accelerate`/`vDSP`, полоса 30–150 Гц, адаптивный порог,
  `CHHapticEngine` transient-события, динамическая сила/резкость, cooldown 80 мс.
- **3D-сканер глубины**: задний LiDAR (`sceneReconstruction(.mesh)` + raycast по центру экрана)
  на iPhone 12 Pro и новее, фронтальный TrueDepth (`ARFaceTrackingConfiguration`) на XS Max и новее,
  автовыбор датчика и переключатель при наличии обоих.
- **Тактильный парктроник**: тики Taptic Engine с частотой, зависящей от расстояния.
- **Настройки**: сила вибрации (10–100 %), резкость отклика, чувствительность к басу,
  тест Taptic Engine, карточка «О приложении» со ссылками на репозиторий и релиз.
- **Инфраструктура**: XcodeGen-спека, CI на `macos-latest`, неподписанный `vibration.ipa`
  в GitHub Releases и Actions Artifacts.

### Технические детали

- `IPHONEOS_DEPLOYMENT_TARGET = 15.0`, `arm64`, `TARGETED_DEVICE_FAMILY = 1` (iPhone).
- `ARSession` и `AVAudioEngine` останавливаются при уходе с вкладки.
- Анализ звука выполняется на отдельной `DispatchQueue`, UI обновляется с частотой 10–20 Гц.
